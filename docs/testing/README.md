# 비공개 테스트 키트

구글 플레이 정식 출시 전에 필요한 **테스터 12명 이상 × 14일 연속 참여**를 위한 자료입니다.

| 파일 | 용도 |
|---|---|
| [`recruit.md`](recruit.md) | 단톡방·DM에 보낼 모집 글 (짧은 버전, 긴 버전) |
| [`../../test.html`](../../test.html) | 테스터에게 보내는 참여 방법 페이지 → https://sin4691.github.io/lucky21/test.html |
| [`feedback-form.md`](feedback-form.md) | 구글 폼에 그대로 옮길 피드백 질문 |
| [`test-log.md`](test-log.md) | 테스트 기간 기록 + 프로덕션 액세스 신청 답변 초안 |

## 순서

1. 플레이 콘솔 **테스트 및 출시 > 비공개 테스트 > 트랙 만들기** (이름 예: `closed-1`)
2. 내부 테스트에서 확인한 버전을 비공개 테스트로 **승격** (또는 같은 .aab 업로드)
3. **테스터** 탭 → 이메일 목록에 모집한 Gmail 추가 (여유 있게 15명 이상)
4. 국가: 대한민국(+필요한 나라) 선택 → 검토 전송. 첫 비공개 테스트는 구글 검토에 며칠 걸릴 수 있습니다
5. 검토가 끝나면 `test.html` 링크를 보내기. **검토 전에 보내면 테스터에게 오류가 납니다**
6. 매일 플레이 콘솔 **비공개 테스트 > 테스터** 에서 참여 인원이 12명 아래로 내려가지 않는지 확인
7. 14일이 지나면 대시보드의 **프로덕션 액세스 신청** → `test-log.md`의 답변 초안 사용
