# Google Play 스토어 등록 정보

Play Console → **앱 → 스토어 등록정보 → 기본 스토어 등록정보**에 그대로 붙여 넣으면 됩니다.

## 앱 이름 (30자 이내)

```
LUCKY 21: 블랙잭 로그라이크
```

## 간단한 설명 (80자 이내)

```
블랙잭에 덱빌딩을 더한 로그라이크. 부적과 카드로 칩 × 배수 공식을 키워 8스테이지를 돌파하세요.
```

## 자세한 설명 (4000자 이내)

```
딜러를 이기면 끝이 아닙니다. 얼마나 크게 이기느냐가 중요합니다.

LUCKY 21은 블랙잭에 덱빌딩 로그라이크를 결합한 싱글 플레이 카드 게임입니다.
딜러를 이기면 카드의 칩 × 배수만큼 점수를 얻고, 8개 스테이지의 목표 점수를 넘기면 승리합니다.

■ 내 덱을 직접 설계하는 블랙잭
· 딜러와 따로, 나만의 덱에서 카드를 뽑습니다.
· 필요 없는 카드는 빼고, 원하는 카드는 넣고, 금박·유리·보석·행운으로 강화하세요.
· 남은 덱 기준으로 다음 히트의 버스트 확률을 바로 보여 줍니다.

■ 점수 공식을 바꾸는 부적 39종
· "하트 카드 1장당 배수 +3", "3장 이상으로 만든 21이면 배수 ×7" 같은 부적을 조합해 나만의 빌드를 만드세요.
· 부적은 왼쪽부터 순서대로 발동하므로 배치 순서도 전략입니다.

■ 한 번 쓰는 트릭 카드 5종
· 다음 카드 미리 보기, 다음 카드를 10으로 바꾸기, 마지막 카드 바꿔치기 등 위기를 넘기는 한 수.

■ 판을 뒤집는 보스 10종
· 딜러가 18에서야 멈추고, 하트가 봉인되고, 더블다운이 막힙니다. 보스마다 다른 공략이 필요합니다.

■ 시작 덱 5종과 도감
· 하트만 가득한 덱, 2~5가 없는 하이롤러 덱, 금박 덱, 부자 덱.
· 업적을 달성하면 새로운 덱과 부적이 열립니다.

■ 그리고
· 8스테이지를 깬 뒤에도 계속되는 엔드리스 모드
· 처음 하는 분을 위한 플레이 중 튜토리얼
· 빌드가 완성된 상태로 바로 해 보는 데모 모드
· 중간에 꺼도 이어하기 지원
· 광고 없음, 인앱 결제 없음, 인터넷 연결 없이 플레이

※ 이 게임에는 실제 돈이나 경품이 걸리지 않습니다. 게임 속 골드는 상점에서만 쓰는 가상 재화이며 현금으로 바꿀 수 없습니다.
```

## 그 밖의 설정

| 항목 | 입력값 |
|---|---|
| 앱 카테고리 | 게임 → **카드** |
| 태그 | 카드, 로그라이크, 덱빌딩, 싱글 플레이어, 오프라인 |
| 개인정보처리방침 URL | https://sin4691.github.io/lucky21/privacy.html |
| 연락처 이메일 | 필수 항목이고 스토어에 공개됩니다. 공개해도 되는 주소를 따로 만들어 쓰는 걸 권장 |
| 광고 포함 | 아니요 |
| 인앱 상품 | 없음 |

## 앱 콘텐츠 설문 답변 요약

- **데이터 보안**: 데이터를 수집하거나 공유하지 않음. 기록과 저장은 기기 안(localStorage)에만 있습니다.
- **콘텐츠 등급(IARC 설문)**: 도박 관련 질문에서 "실제 돈을 걸지 않는 모의 도박(카지노 카드 게임)"에 해당한다고 답합니다. 이 항목 때문에 전체이용가보다 높은 등급이 나올 수 있습니다.
- **타겟층**: 만 18세 이상으로 설정하는 것이 안전합니다. 카지노 소재 게임은 아동 대상 정책 심사가 까다롭습니다.
- **뉴스 앱 / 정부 앱 / 금융 기능 / 건강**: 모두 해당 없음.
